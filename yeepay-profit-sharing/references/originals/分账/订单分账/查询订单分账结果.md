# 查询订单分账结果

## 基本信息

- **API ID**: 42505ab78dad4f668beebd8f123dfa5d
- **API 分组**: divide
- **请求路径**: `/rest/v1.0/divide/query`
- **请求方法**: GET
- **描述**: 调用该接口查询分账结果
- **安全需求**: YOP-RSA2048-SHA256, YOP-SM2-SM3
- **最后更新时间**: 2025-11-10 11:20:27

## 请求参数

### application/x-www-form-urlencoded


| 参数名              | 参数说明    | 类型     | 是否必填 | 描述           | 示例值                     |
| ---------------- | ------- | ------ | ---- | ------------ | ----------------------- |
| parentMerchantNo |         | string | 是    | 发起方商编        | sample_parentMerchantNo |
| merchantNo       | 收款商户编号  | string | 是    | 收款商户编号       | sample_merchantNo       |
| divideRequestId  | 商户分账请求号 | string | 是    | 商户分账请求号      | sample_divideRequestId  |
| orderId          | 商户收款请求号 | string | 是    | 原支付订单的商户订单号  | sample_orderId          |
| uniqueOrderNo    | 易宝收款订单号 | string | 否    | 收款交易对应在易宝的单号 | sample_uniqueOrderNo    |
