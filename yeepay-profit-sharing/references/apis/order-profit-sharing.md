# 订单分账

## 文档定位

本页用于订单分账全链路接入，覆盖申请、查询、资金归还与完结分账。

- 字段规则、状态流转与错误处理以“接口规范”原文为准。
- 接口编排和阶段顺序以分账对接指引原文为准。

## 阅读顺序（建议）

1. 实现订单分账申请与结果查询。
2. 实现资金归还申请与结果查询。
3. 按业务需要实现完结分账。
4. 阅读分账对接指引核对总体流程与阶段约束。

## Agent 执行提示

- 对每个资金动作都应提供查询补偿能力，防止状态不一致。
- 分账、归还、完结是不同阶段动作，不可混用状态判断。
