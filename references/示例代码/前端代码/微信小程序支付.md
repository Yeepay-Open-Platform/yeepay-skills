# 小程序支付

## 获取登录凭证（code）

```javascript
wx.login({
  success (res) {
    if (res.code) {
      //发起网络请求
      wx.request({
        url: 'https://example.com/onLogin',
        data: {
          code: res.code
        }
      })
    } else {
      console.log('登录失败！' + res.errMsg)
    }
  }
})
```

## 唤起微信小程序支付

> 服务端在易宝平台下单后，会返回 `paySign` 参数，这个参数为一个 JSON 串，包含支付所需的所有签名信息(paySign)，通过 JSON.parse() 解析。

```javascript
wx.requestPayment({
  timeStamp: '',
  nonceStr: '',
  package: '',
  signType: 'MD5',
  paySign: '',
  success (res) { },
  fail (res) { }
})
```
