# 示例代码（占位）

本目录用于存放可直接复用的代码示例。**本版仅占位，内容按需补充。**

规划内容：

| 子目录/文件 | 用途 | 状态 |
|-------------|------|------|
| `加验签/` | 请求加签、响应验签示例（RSA / SM） | 占位 |
| `加解密/` | 报文加密、解密示例（RSA / SM） | 占位 |
| `接收回调/` | 回调接收 + 验签 + 幂等处理示例（3 种，待定义具体三种形态） | 占位 |
| `前端/` | prePayTn 解析与各支付方式前端唤起示例 | 占位 |

约定：

- 示例代码不得包含真实密钥；密钥用占位符并注明从配置注入。
- 与接口字段相关的部分以在线 `doc_md` 文档为准，示例只演示流程与加解密。
- 签名/验签/加密机制的权威说明见 `../平台文档/平台规范/安全认证/`。
