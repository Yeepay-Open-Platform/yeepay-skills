# 主扫支付（微信/支付宝聚合码）

**用户扫商户**展示的**一码多渠道聚合码**完成支付（同一张码，微信/支付宝等都能扫）。

> 接口字段以在线文档为准：按下表 catalog id 在 `../api-index.yaml` 取其 `doc_md` 链接，执行
> `curl -sS "<doc_md>"` 后再实现（单文件含字段/示例/错误码/示例代码）。

## 场景 → 接口

| 用途 | catalog id | 方法 | 路径 |
|------|-----------|------|------|
| 生成聚合订单码 | `aggpay-pay-link` | POST | `/rest/v1.0/aggpay/pay-link` |
| 查单 | `trade-order-query` | GET | `/rest/v1.0/trade/order/query` |

支付结果回调：`aggpay-pay-link` 的 `notify_spi: trade.pay-result`。

## 流程

1. 后端调 `aggpay-pay-link` 生成聚合订单码（返回收银台链接）。
2. 将链接生成二维码展示。
3. 用户用任意支持渠道 App 扫码，进入聚合收银台选择渠道支付。
4. 以「支付结果通知 + 查单」确认终态。

## 必读规则

1. `../../平台文档/平台规范/安全认证/鉴权认证机制(RSA).md`（请求签名）。
2. `../../平台文档/平台规范/安全认证/结果通知(RSA).md`（回调验签）。

## 易错点

- 聚合码用 `aggpay-pay-link`，不是 `aggpay-pre-pay`，接口不同。
- 聚合码是"一码通吃"；若需每渠道独立码用 `主扫支付（独立码-线上PC）.md`。
- 终态以后端为准。
