# 提现

将商户账户余额提现到提现卡（提现下单 + 查询 + 提现卡管理）。

> 接口字段以在线文档为准：按下表 catalog id 在 `../api-index.yaml` 取其 `doc_md` 链接，执行
> `curl -sS "<doc_md>"` 后再实现（单文件含字段/示例/错误码/示例代码）。

## 场景 → 接口

| 用途 | catalog id | 方法 | 路径 |
|------|-----------|------|------|
| 提现下单 | `withdraw-order` | POST | `/rest/v1.0/account/withdraw/order` |
| 提现查询 | `withdraw-query` | GET | `/rest/v1.0/account/withdraw/system/query` |
| 提现卡修改/注销 | `withdraw-card-modify` | POST | `/rest/v1.0/account/withdraw/card/modify` |

提现结果回调：`withdraw-order` 的 `notify_spi`（以在线 notify 文档为准）。

## 流程

1. 确认提现卡已绑定可用。
2. 用业务唯一单号调 `withdraw-order` 发起提现。
3. 以 `withdraw-query` 或提现结果通知确认终态。
4. 超时/未知先查询再决定是否重试。

## 必读规则

1. `../../平台文档/平台规范/安全认证/鉴权认证机制(RSA).md`（请求签名）。
2. `../../平台文档/平台规范/安全认证/结果通知(RSA).md`（回调验签）。

## 易错点

- 提现单号业务唯一；**严禁重复出款**，超时务必先查再重试。
- 提现卡管理（修改/注销）有独立风控规则，以在线文档为准。
- 提现金额、手续费、到账时间以平台配置与文档为准。
- 禁止输出完整卡号/证件号。

## 排障

- 出款状态以查询接口/提现结果通知为准；业务错误码见接口 `doc_md` 的「错误码」章节，平台码见 `../../平台文档/开始对接/平台错误码说明.md`。
