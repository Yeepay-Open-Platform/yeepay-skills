# 配置IP白名单

## 一、什么是IP白名单？

为了提高商户服务器访问API网关的安全性，避免商户因应用私钥泄漏等原因导致业务受损，易宝开放平台提供了 IP 白名单机制，商户可基于该机制对资金操作类敏感接口配置 IP 白名单。

API网关将基于商户配置的 IP 白名单，校验商户请求的来源 IP。

若来源 IP 不在配置的 IP 白名单范围内，则API网关将拦截对应的非法请求。  
  
注意对接以下接口必须配置IP白名单：

/rest/v1.0/balance/yop-group-remit/transfer-confirm  
/rest/v1.0/balance/transfer_batch_send  
/rest/v1.0/balance/transfer_send  
/rest/v1.0/balance/cash

## 二、配置IP白名单

**控制台路径**：登录 [控制台](https://open.yeepay.com/developer-center) > **我的应用** > **IP白名单**。

在 IP 白名单管理页面可新增、修改、删除、查询规则。首次使用可点击 **立即设置**。

> 截图参考：![配置IP白名单1](https://open.yeepay.com/attachments/2026/02/02/doc_17KJ0yqVuzI_1770026105621.png)

平台支持部分接口、全部接口两种配置 IP 白名单的方式。部分接口是指您已签约的高风险接口，全部接口是指所有接口（不包含返回302的重定向接口）。

**注意**：若应用为某接口配置了部分接口 IP 白名单，同时也配置了全部接口 IP 白名单，则该接口以配置的部分接口 IP 白名单为准，API网关会忽略全部接口中配置的 IP 白名单，详情参见 IP白名单拦截规则。

#### 1、部分接口IP白名单配置

该场景主要是针对易宝开放平台提供的资金操作类敏感接口配置 IP 白名单，若商户需要只对这些接口做来源 IP 管控，那么商户可通过配置部分接口 IP 白名单的方式来设置。通常该类商户有多个应用并部署在不同机房，而商户只想保护需要请求资金操作类敏感接口的出口IP。

#### 2、全部接口IP白名单配置

全部接口是指开放平台的所有接口（不包括返回302的重定向接口）。

适用场景：

-   **场景**1: 开发者想要配置的接口不在**资金操作类敏感接口** 中，无法通过 部分接口配置 方式设置 IP 白名单。
-   **场景**2: 开发者希望针对全部接口设置统一的IP白名单。

#### 3、当前开放平台支持开发者在配置 IP 时使用几种格式：

1.  支持单 IPv4 地址（如123.103.49.137）；
2.  支持 IPv4/子网掩码（如123.103.49.137/24）；
3.  支持单 IPv6 地址（如2409:8800:8813:208a:617a:6125:d33f:79e0、::79e0）；
4.  支持 IPv6/网络位（如2409:8800:8813::/64）；
5.  支持以上几种格式 IP 配置的组合，每行只有一个IP。

**注意**：配置的 IP 为开发者服务器的出口IP，请在配置前仔细检查 IP正确性、完整性。

## 三、新增IP白名单

### 1、新增全部接口IP白名单

1.  在**IP 白名单管理** 页面点击**添加规则**，在弹框**添加规则** 中选择**全部接口**，点击**下一步** 配置 IP。选择全部接口，配置页面将不会显示详细接口列表。![配置IP白名单2.png](https://open.yeepay.com/attachments/2026/02/02/doc_17KJ53CGXBo_1770026160740.png)
2.  在弹框**添加规则** 中配置IP，配置完成后点击**确认。**![添加规则-全部接口（IP白名单）.png](https://open.yeepay.com/attachments/2026/02/02/doc_17KJ88rkPDM_1770026202605.png)

### 2、新增部分接口IP白名单

该场景主要是针对易宝开放平台提供的资金操作类敏感接口配置 IP 白名单，若商户需要只对这些接口做来源 IP 管控，那么商户可通过配置部分接口 IP 白名单的方式来设置。

通常该类商户有多个应用并部署在不同机房，而商户只想保护需要请求资金操作类敏感接口的出口IP。

注意：若应用为某接口配置了部分接口 IP 白名单，同时也配置了全部接口 IP 白名单，则该接口以配置的部分接口 IP 白名单为准，API网关会忽略全部接口中配置的 IP 白名单，详情参见 IP白名单拦截规则。

1.  在**IP 白名单管理** 页面点击**添加规则**，安全验证通过后，在弹框中，选择要拦截的接口为**部分接口** ，配置页面将展示**当前应用已签约的高风险接口列表**（若应用想配置非高风险接口的 IP 白名单，请选择**全部接口**），开发者可根据自身诉求勾选对应的接口并配置 IP 白名单。![添加IP白名单.png](https://open.yeepay.com/attachments/2026/02/03/doc_17LsK4r9ciu_1770107807216.png)
2.  勾选完接口后，点击**下一步** 配置具体的 IP 列表，IP 配置规则详情请参见**IP白名单配置规则**。IP 配置完之后，点击**确定**，完成 IP 白名单添加。  
    ![添加IP白名单.png](https://open.yeepay.com/attachments/2026/02/03/doc_17LsbsnacKW_1770108048343.png)

## 四、修改IP白名单

### 1.修改全部接口的IP白名单

1.  在**IP白名单管理** 页面，在所需修改的IP白名单规则操作列点击**修改**。![修改全部接口IP白名单1.png](https://open.yeepay.com/attachments/2026/02/03/doc_17LsifvVFsu_1770108140327.png)
2.  安全验证通过后，在**修改规则** 中重新配置IP，配置完成后点击**确认。**!\[修改规则（配置IP）.png\]![ip白名单4.png](https://open.yeepay.com/attachments/2026/02/03/doc_17LsqeE5Nzc_1770108248293.png)

### 2.修改部分接口的IP白名单

1.  在**IP 白名单管理** 页面，在所需修改的 IP 规则操作列点击**修改**。![ip白名单5.png](https://open.yeepay.com/attachments/2026/02/03/doc_17LswdvTAAa_1770108329481.png)
2.  安全验证通过后，在弹框**修改规则** 中重新勾选接口列表，点击**下一步**。  
    ![ip白名单6.png](https://open.yeepay.com/attachments/2026/02/03/doc_17Lt08zFBGS_1770108376892.png)
3.  在弹框**修改规则** 中重新配置IP。  
    ![ip白名单7.png](https://open.yeepay.com/attachments/2026/02/03/doc_17Lt3QQoGJM_1770108421329.png)

## 五、删除IP白名单

在 **IP 白名单管理** 页面，在所需删除的IP规则操作列点击 **删除**，在弹框中点击 **确认删除** ，安全验证通过后，即可删除成功。  
![ip白名单8.png](https://open.yeepay.com/attachments/2026/02/03/doc_17Lt6fbHOjI_1770108465270.png)

## 六、IP白名单拦截规则

开放平台支持部分接口、全部接口两种配置 IP 白名单的方式。部分接口是指您已签约高风险接口，全部接口是所有接口（不包含返回302的重定向接口）。针对这两种配置方式，开放平台对于

**不同场景的校验规则如下：**

-   场景1：应用仅配置了部分接口 IP 白名单，API网关针对该应用的接口请求，会判断该 IP 白名单中是否包含请求中的接口。若包含，API网关则以该 IP 白名单校验请求来源 IP。
-   场景2：应用仅配置了全部接口 IP 白名单，API网关针对该应用的所有接口请求，都会使用该 IP 白名单来校验请求来源 IP。
-   场景3：若应用既配置了部分接口 IP 白名单，也配置了全部接口 IP 白名单，API网关针对该应用的接口请求，会先判断部分接口 IP 白名单中是否包含该请求中的接口。若包含，API网关则以命中的部分接口 IP 白名单校验该请求来源 IP，同时忽略全部接口 IP 白名单；若不包含，API网关则以全部接口 IP 白名单校验请求来源 IP。

**针对场景3，举例说明。例如应用A存在以下4个IP白名单配置：**

-   配置1：部分接口IP白名单，接口 /rest/v1.0/std/trade/order，IP配置 192.168.10.1  
    配置2：部分接口IP白名单，接口 /rest/v1.0/std/trade/order，/rest/v1.0/std/trade/orderclose，IP配置 192.168.10.2  
    配置3：部分接口IP白名单，接口/rest/v1.0/std/trade/orderquery，IP配置 192.168.10.3  
    配置4：全部接口IP白名单，IP配置 192.168.10.4

若应用A调用 /rest/v1.0/std/trade/order 的请求来源 IP 是 192.168.10.4，API网关收到该请求后，发现该接口存在以部分接口方式配置的 IP 白名单（配置1、配置2），API网关将只使用命中的部分接口 IP 白名单（配置1、配置2）校验来源 IP，校验结果是来源 IP 不在白名单中，尽管该请求的来源 IP 在该应用的全部接口 IP 白名单中（配置4），但API网关依旧会拦截该请求。
