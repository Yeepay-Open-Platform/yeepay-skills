# 配置国际密钥（RSA）

## 一、配置前准备

1. 准备好登录 [控制台](https://open.yeepay.com/developer-center) 的账号。
2. 已制备商户 RSA 密钥对（私钥本地保管，公钥待上传）：
   - 本地生成：见 `工具与支持/开发工具/密钥工具.md`，或联调用 `scripts/gen_keypair.py --alg rsa`。
   - 部分产品（如代付代发）需 CFCA 证书，见 `CFCA证书制备.md`。

## 二、首次配置 RSA 公钥

**控制台路径**：**我的应用** > **密钥配置**。

1. **公钥类型**选择 **国际（RSA2048）**。
2. **密钥格式**二选一：
   - **文本**：粘贴 RSA 商户公钥内容（PKCS#8 / X.509 Base64）。
   - **证书**：选择已制备的 RSA CFCA 证书，或点击 **上传证书文件**（支持 `.p7b`、`.cer`）。
3. 完成**绑定手机号**短信验证。
4. 提交后页面提示密钥设置成功。

## 三、修改商户公钥

私钥泄漏等情况下需轮换密钥：

1. **我的应用** > **密钥配置** > 点击 **设置公钥**。
2. 填写新商户公钥（文本或证书，同首次配置）。
3. 完成手机号验证。
4. 修改成功后，建议**立即吊销**旧公钥（见下节）。

## 四、密钥变更吊销 / 撤销

- **立即吊销**：变更成功后弹窗点击 **立即吊销**，二次确认后旧密钥失效。
- **撤销变更**：若新密钥配置有误，可点击 **撤销变更** 回退到旧密钥。

## 五、查看摘要与易宝公钥

- **摘要信息（数字签名）**：密钥配置页可查看商户公钥指纹，用于核对是否上传正确公钥。
- **易宝公钥**：RSA 类型可 **查看** 并 **复制** 易宝平台公钥，用于不使用 SDK 时的回调验签或手工加密。

> 使用 Java SDK 最新版时，通常无需本地配置易宝公钥（SDK 自动管理证书）。
