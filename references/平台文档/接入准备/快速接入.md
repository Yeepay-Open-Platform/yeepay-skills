## 一、商户入网并签约产品

### 1 查看产品开通情况

在【[控制台](https://open.yeepay.com/developer-center)】>【 开发服务】>【接入诊断】 页面，确认已开通的产品和权限。请仔细核对您需要使用的产品功能是否已在控制台开通，并确认其状态为"正常"。

**操作要点**：

- 检查产品开通状态
- 确认产品功能与您的业务需求匹配
- 如有未开通产品，请联系您的客户经理申请开通

### 2 检查应用配置

- **查看应用信息**：确认应用标识（AppKey）和应用名称，这是您应用的唯一身份标识
- **确认应用权限范围**：验证应用是否具备所需产品的访问权限，确保权限配置完整

## 二、密钥配置

### 1 密钥制备

1. 下载并安装 [密钥工具](https://open.yeepay.com/docs/open/developer/tools/key-tools)（支持 Windows/Mac/Linux 多平台）
2. 根据您的安全需求选择密钥类型：
  - [制备普通密钥](https://open.yeepay.com/docs/platform/sign_rsa/generate-rsa-key-pairs)：适用于一般业务场景，操作简便
  - [制备CFCA证书](https://open.yeepay.com/docs/open/developer/prepare/cfca-make)：适用于对安全性要求更高的金融场景，提供更强的安全保障

#### 密钥类型

- **商密密钥(SM)**：商密算法，符合国家密码局安全标准，推荐 Java 语言开发者使用，提供更高安全性和合规性
- **国际密钥(RSA)**：国际通用加密算法，适用于更多开发语言，兼容性更好，适合多语言开发环境

**选择建议**：

- 如果您主要使用Java开发，建议选择商密密钥(SM)
- 如果您使用其他语言开发或有跨国业务，建议选择国际密钥(RSA)

### 2 密钥配置

在 【[控制台](https://open.yeepay.com/developer-center)】>【 我的应用】>【密钥配置】完成配置：

- [国际密钥(RSA)配置说明](https://open.yeepay.com/docs/open/developer/prepare/key-config-rsa)：上传您的RSA公钥并下载平台公钥
- [商密密钥(SM)配置说明](https://open.yeepay.com/docs-v3/platform/llms.txt)：上传您的SM2公钥并下载平台公钥

# 配置商密证书(SM)

 **安全提示**：密钥配置是确保通信安全的关键步骤，请务必妥善保管私钥，避免泄露。建议将私钥存储在安全的环境中，并限制访问权限。

## 三、SDK 集成

### Java 开发者

#### 方案一：手动集成

1. 在【[控制台](https://open.yeepay.com/developer-center)】>【 开发服务】>【资源工具】下载最新版SDK
2. 参考 [Java SDK 使用说明](https://open.yeepay.com/docs/platform/sdk_guide/java-sdk-guide) 进行集成：
  - 添加 Maven 依赖或导入 JAR 包到项目中
  - 配置客户端参数（AppKey、私钥路径等）
  - 按照示例实现接口调用逻辑

#### 方案二：使用 VSCode 插件

1. 安装 [VSCode YOP 插件](https://open.yeepay.com/docs/platform/developTools/developer_tools_vscode)，提升开发效率
2. 使用插件生成示例代码：
  - 选择所需接口和功能
  - 配置应用参数和环境
  - 自动生成标准调用代码
3. 根据业务需求修改和优化代码，集成到您的项目中

**优势**：

- 可视化操作界面，降低学习成本
- 自动生成规范代码，减少错误
- 集成测试功能，便于调试

### 其他语言开发者

#### PHP

- 登录开发者中心下载最新版 PHP SDK
- 按照文档说明进行配置和使用：
  - 安装必要依赖库
  - 初始化客户端配置
  - 调用接口方法实现业务功能

#### .NET、Python、Node.js、Go

- 下载对应语言的 [基础 SDK](https://open.yeepay.com/docs/open/developer/tools/sdk)
- 参考详细示例代码进行开发：
  - 配置应用参数和环境变量
  - 实现签名验签机制
  - 封装标准化接口调用

#### 其他语言

如果没有您使用的语言SDK，可以参考 [无SDK对接API](https://open.yeepay.com/docs/platform/sdk_guide/no-sdk) 自行实现：

- 按照接口规范构造标准HTTP请求
- 实现签名算法和安全验证
- 处理响应结果和异常情况

## 四、开发对接

### 1 API 对接准备

- **了解业务场景和模型**：明确您的业务需求与平台能力的匹配点，设计合理的业务流程
- **确定需要使用的具体接口**：根据业务流程选择合适的接口组合，避免冗余调用
- **查看详细的 API 文档**：深入了解接口的请求参数、响应结果和业务规则，确保正确实现
- **了解签名算法和参数规范**：掌握安全验证机制，确保请求能够通过平台的安全验证

### 2 关键开发要点

- **严格按照接口文档规范传递参数**：注意必填项、参数格式和长度限制，避免因参数错误导致调用失败
- **正确处理接口返回结果**：根据返回码判断交易状态，合理处理成功和异常情况
- **实现异步通知接收接口**：开发稳定可靠的回调接口，确保能够接收并处理平台的异步通知
- **注意接口调用频率限制**：遵循平台的调用频率规范，实现合理的请求控制，避免触发限流措施

### 3 异步通知处理

- **实现通知接收接口**：开发专门的服务端接口接收平台异步通知，确保高可用性
- **验证通知签名**：使用平台公钥验证通知的真实性，防止伪造请求
- **处理业务逻辑**：根据通知内容更新本地订单状态，确保数据一致性
- **返回正确的响应格式**：接收成功后返回"success"字符串，避免平台重复发送通知

 **重要提示**：务必同时实现主动查单接口，在异步通知失败时主动查询订单状态，确保数据一致性。建议设置定时任务，对未收到通知的订单进行状态查询，构建完善的订单状态管理机制。

## 六、安全建议

### 1 密钥管理

- **妥善保管私钥**：将私钥存储在安全的位置，严格控制访问权限，避免泄露
- **定期更新密钥**：建议每3-6个月更新一次密钥，降低安全风险
- **使用安全的密钥存储方式**：考虑使用硬件加密模块或专业密钥管理系统，提升安全等级

### 2 通信安全

- **使用 HTTPS 协议**：确保传输层安全，防止数据被窃听或篡改
- **验证请求签名**：验证所有来自平台的请求签名，确保请求真实性
- **加密敏感数据**：对敏感信息进行加密处理，保护用户隐私和账户安全

### 3 业务安全

- **实现幂等性控制**：为所有交易请求设计唯一标识，防止重复请求导致的数据异常
- **做好日志记录**：记录详细的操作日志和交易日志，便于问题排查和安全审计
- **增加必要的业务校验**：实施金额限制、交易频率控制、异常交易监控等安全措施
