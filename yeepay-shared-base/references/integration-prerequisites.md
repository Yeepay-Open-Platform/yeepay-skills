# 接入前准备清单（摘要）

本文为接入准备摘要，便于快速核对。  
权威依据以原始文档为准：`references/originals/开发文档`。

## 1. 开通与应用检查

- 确认商户入网并签约所需产品。
- 在开发者中心确认产品开通状态、应用信息与权限范围。
- 核对应用标识（AppKey）等关键配置项。

## 2. 密钥与安全配置

- 完成密钥制备与平台侧密钥配置（RSA/SM 以实际接入要求为准）。
- 妥善保管私钥，避免泄露。
- 接口通信使用 HTTPS。

## 3. 接入方式与调用规范

- 可使用官方 SDK；无 SDK 场景需按接口规范构造 HTTP 请求。
- 按签名/验签规范实现请求认证与安全校验。
- 严格按接口文档传递参数并处理返回结果。

## 4. 异步通知与终态确认

- 实现异步通知接收接口。
- 对通知执行签名验证并处理业务状态更新。
- 同步实现主动查询能力，用于通知异常时确认最终状态。

## 5. 测试与联调

- 使用沙箱环境进行功能与异常场景测试。
- 与技术支持完成联调，确认核心流程可用。

## 6. 上线前检查（摘要）

- 生产环境应用、密钥、产品与接口开通状态已核对完成。
- 配置项已切换为生产专用配置。
- 全链路联调与回归测试通过。
- 网络与安全策略（端口、防火墙、安全组等）已核对。
