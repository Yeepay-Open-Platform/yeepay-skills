# 无 SDK 对接 API（RSA）

本文用于指导在未使用官方 SDK 时，按 OpenAPI 规范完成 HTTP 方式对接。

## 1. 适用场景

- 官方暂未提供目标语言 SDK。
- 需要自行封装请求链路或开发自定义 SDK。
- 需要明确掌握签名、验签与请求构建的底层过程。

## 2. 基础约束

- 字符编码使用 UTF-8。
- Base64 使用 URL 安全模式（`+` -> `-`，`/` -> `_`）。
- 全部请求必须使用 HTTPS。
- 请求头上限 8KB、请求体上限 6MB（文件类参数以业务接口限制为准）。
- 生产环境推荐优先使用官方 SDK；无 SDK 方案需自行承担实现与维护成本。

## 3. 对接前准备

- 已开通应用与目标接口权限，获取 `appKey`。
- 已完成 RSA 密钥配置，并妥善保存商户私钥、平台公钥。
- 已明确目标 API 的 `Content-Type`、请求方法、参数定义与响应格式。
- 已具备回调接收能力，并可执行回调验签与幂等处理。

## 4. 请求构建流程

建议按以下顺序构建请求：

1. 组装业务参数（禁止传 `null`）。
2. 生成请求头：
  - `x-yop-request-id`（唯一值，必须参与签名）
  - `x-yop-appkey`（必须参与签名）
  - `x-yop-content-sha256`（必须参与签名）
  - `Authorization`（按 RSA 鉴权规范生成）
3. 构造规范请求串（方法、URI、查询串、签名头）。
4. 使用商户私钥签名，拼装 `Authorization`。
5. 按 API 要求提交 GET/POST（JSON、form、multipart）。

## 5. `x-yop-content-sha256` 计算规则

- GET 请求：对空字符串计算 SHA-256。
- POST + JSON：对完整 JSON 请求体计算 SHA-256。
- POST + form/multipart：对“非文件参数”排序编码后计算 SHA-256。

## 6. URL 与网关

- 网关地址以易宝开放平台“当前 API 文档页/控制台配置”为准。
- 实际接入时，建议在联调与上线前逐项核对：
  - 接口所属域（openapi 或 yos）
  - 环境（测试/生产）与网关是否匹配
  - API 路径与版本是否与文档一致

## 7. 响应处理与验签

- 先读取 HTTP 状态码、`x-yop-request-id`、`x-yop-sign`。
- JSON 响应需校验平台签名（平台公钥）。
- 文件下载响应按文件流处理，并保留请求号用于排障。
- 返回成功不等于业务终态完成，仍需结合异步通知与查询接口确认。

## 8. 错误处理建议

- 参数类错误：先核对接口文档的必填项、格式、长度与编码规则。
- 验签失败：核对密钥配对关系、签名串拼装、参数排序与编码逻辑。
- 超时与网络错误：合理设置连接/读取超时，采用“先查状态再重试”策略。
- 对可重试错误使用指数退避；业务明确失败不盲目重试。

## 9. 安全与稳定性建议

- 私钥不入库，不输出到日志，不通过 IM/邮件传播。
- 关键日志脱敏，仅保留排障需要的最小字段。
- 接口调用链路建议使用连接池与统一超时配置。
- 增加防重放控制（请求 ID 去重 + 时间窗口校验）。
