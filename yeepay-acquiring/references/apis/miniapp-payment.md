# 小程序支付

## 文档定位

本页用于小程序支付接入，先明确流程再实现接口。

- 字段定义、签名、返回码与错误处理以“接口规范”原文为准。
- 页面唤起路径与链路串联以“接入流程”原文为准。

## 阅读顺序（建议）

1. 先读接入指引确定前后端职责与拉起步骤。
2. 按接口规范实现下单与查询。
3. 按需实现公众号配置接口（异步）。
4. 以回调通知与查询结果确认支付终态。
