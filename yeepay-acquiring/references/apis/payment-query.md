# 收单查询接口

## 文档定位

本页汇总各支付方式的查询订单接口，用于统一实现终态确认能力。

## 使用说明

- 交易结果以查询或回调确认为准，不以前端展示为准。
- 建议统一封装查询能力，按支付场景路由到对应查询接口。

- `../originals/收单/小程序支付/查询订单.md`
- `../originals/收单/浏览器H5支付/查询订单.md`

- `../originals/收单/主扫支付/微信支付宝独立码（线上 pc 场景）/查询订单.md`
- `../originals/收单/主扫支付/微信支付宝聚合码/查询订单.md`

## Agent 执行提示

- 下单、退款、分账等写操作出现超时或未知结果时，优先调用对应查询接口确认状态。
- 统一查询层应返回标准化终态（成功/失败/处理中），避免各场景重复实现状态映射。
