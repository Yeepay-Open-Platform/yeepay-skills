# 浏览器页面支付

## 文档定位

本页用于浏览器 H5 支付场景接入，覆盖下单、查询与回调相关接口。

- 接口字段、签名、错误码以“接口规范”原文为准。
- 页面跳转链路和前后端协同以“接入流程”原文为准。

## 阅读顺序（建议）

1. 先读接入流程确认浏览器拉起支付链路。
2. 实现下单与查询接口。
3. 按需实现公众号配置接口（异步）并接收通知。
4. 通过查询接口补偿确认最终状态。
