# 一、被扫业务介绍

商户收银使用扫码设备读取用户钱包（微信、支付宝、云闪付）付款码以后，将二维码信息传送给商户的后台服务器，后台调用该接口发起付款

# 二、业务流程

1. 前提条件：
  1. 收单商户需开通：商家扫码支付宝线下、商家扫码微信线下两个产品
  2. 户完成微信、支付宝子商户号认证

# 三、对接参数

## 3.1 请求参数

**请求地址：****/rest/v1.0/aggpay/pay**

**必传参数：**

merchantNo= 收款商编

orderId = 请求订单号（商家自定义）

orderAmount = 订单金额

payWay = MERCHANTSCAN

authCode = 付款码；商户自采设备进行微信刷脸付时，需要先调【获取刷脸付调用凭证】接口获取authInfo，然后调微信获取facecode，作为授权码传入

userIp =用户真实支付的ip地址

terminalId =扫码设备编号

scene = OFFLINE

**选传参数**

expiredTime = 订单截止时间，不传默认24小时后失效

notifyUrl = 支付结果通知地址

channel =渠道类型

fundProcessType =分账标识
