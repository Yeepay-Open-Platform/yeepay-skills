# 实名认证（微信/支付宝/云闪付支付前置准备）

商户入网后，会进行微信、支付宝商户报备，报备通过后产品开通；产品开通后需要进行微信、支付宝实名认证，否则无法正常使用聚合产品。入网主流程见 `入网.md`。

**！！开通聚合支付产品均涉及报备（报备：商户通过易宝在微信/支付宝侧报备）！！**

汇总概述：如果是小程序接入，需完成报备、实名认证（所谓的开户意愿确认）、微信信息配置（appid）；如果是微信公众号，则在小程序的基础上还需要 appsecret、mp 文件、授权支付路径等配置。

> 接口字段以在线文档为准：按下表 catalog id 在 `../api-index.yaml`（`merchant-netin` 分组）取其 `doc_md`，执行
> `curl -sS "<doc_md>"` 后再实现（单文件含字段/示例/错误码/示例代码）。

| 用途 | catalog id | 方法 | 路径 |
|------|-----------|------|------|

## 微信商户号实名认证的两种方式（任商户选择）

1. **线下认证方式**（无需开发）：
   - 获取渠道商的拓展二维码：渠道商后台 <https://pay.weixin.qq.com/partner/public/home>，由主商编入网的联系人扫码登录。
   - 路径：特约商户管理 - 服务商功能 - 拓展二维码下载。
   - 下载二维码后展示给商户，由商户入网时传入的联系人或法人对应的微信扫码认证。
2. **易宝 API 认证方式**：通过 `mer-wechatauth-apply` 传入实名认证需要的商户信息，同时获取二维码，商户扫码完成认证授权。接入指引：<https://open.yeepay.com/docs/products/fwssfk/quick-start/5fc703f496818f001b300bcd>。

两种方式均可通过 `mer-auth-state-query`（商户授权状态查询）获取商户的认证情况。

## 流程

1. 商户入网完成（见 `入网.md`），微信/支付宝报备通过、产品开通。
2. 微信侧：按上述两种方式之一完成实名认证（开户意愿确认）；支付宝侧：走 `mer-alipayauth-apply` 发起认证。
3. 用 `mer-auth-state-query` / `mer-wechatauth-query` / `mer-alipayauth-query` 确认认证状态为通过后，再开展聚合支付交易。
4. 小程序接入还需完成微信信息配置（appid）；微信公众号在此基础上需 appsecret、mp 文件、授权支付路径等配置。

## 必读规则

1. `../../平台文档/平台规范/安全认证/鉴权认证机制(RSA).md`（请求签名）。

## 易错点

- **实名认证不可省略**：报备通过、产品开通后必须完成微信/支付宝实名认证，否则无法正常使用聚合产品。
- **线下认证方式不需要开发**，同样可以通过 `mer-auth-state-query`（商户授权状态查询）获取商户的认证情况。
- **扫码人身份**：线下认证须由商户入网时传入的**联系人或法人**对应的微信扫码，其他人扫码无效。

## 排障

- 聚合支付产品开通后交易受限：先查认证状态（`mer-auth-state-query` / `mer-wechatauth-query` / `mer-alipayauth-query`）确认是否完成实名认证。
- 业务错误码：见各接口 doc_md「错误码」章节；平台码见 `../../平台文档/开始对接/平台错误码说明.md`。
