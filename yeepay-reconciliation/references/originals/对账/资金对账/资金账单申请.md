# 资金账单申请

## 基本信息

- **API ID**: 9999dea1640046c7b8c36a745c15ff80
- **API 分组**: std
- **请求路径**: `/rest/v1.0/std/bill/fundbill/apply`
- **请求方法**: POST
- **描述**: 商户可以通过该接口申请资金账单，生成的账单默认压缩为zip格式，若无需压缩，可在商户后台进行账单格式配置
- **安全需求**: YOP-RSA2048-SHA256, YOP-SM2-SM3
- **最后更新时间**: 2026-02-10 16:50:01

## 错误码


| 子错误码  | 子错误码描述                                 | 解决方案                                                       |
| ----- | -------------------------------------- | ---------------------------------------------------------- |
| 00000 | 该错误码有多个含义,例如:此商户已有正在生成的文件,请稍后再试。或者返回成功 | 当是查询流水时表示请求成功;当申请账单时返回成功,状态SUCCESS,且带有文件id,此时可以调用资金账单下载接口。 |
| 00001 | 该错误码有多个含义,例如:商户编号不能为空,开始日期不能为空。        | 该错误码有多个含义,例如:商户编号不能为空,开始日期不能为空。                            |
| 00004 | 资金对账文件记录不存在                            | 无交易记录——无需再调用下载接口； 如果申请账单日期不是今天时，无需再发起申请。                   |
| 00011 | 商户关系有误                                 | 商户关系有误                                                     |
| 99999 | 系统异常                                   | 当查询流水时表示调用底层系统异常;当申请账单时，表示自助生成账单失败,请稍后重试。                  |
