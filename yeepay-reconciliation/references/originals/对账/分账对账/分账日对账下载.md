# 分账日对账下载

## 基本信息

- **API ID**: 99b724db525e4c3595a324e73d76acbf
- **API 分组**: std
- **请求路径**: `/yos/v1.0/std/bill/dividedaydownload`
- **请求方法**: GET
- **描述**: 强调：获取对账文件时请以行号来获取对账文件信息，后期易宝可能在后追加参表头参数分账日对账下载，9点后下载前一天的对账文件
- **安全需求**: YOP-RSA2048-SHA256, YOP-SM2-SM3
- **最后更新时间**: 2025-03-17 12:18:03

## 请求参数

### application/x-www-form-urlencoded

| 参数名 | 参数说明 | 类型 | 是否必填 | 描述 | 示例值 |
| ------ | ------ | ------ | ------ | ------ | ------ |
| merchantNo | 子商户编号 | string | 是 | 标准商户:标准商户编号<br>平台商:平台商商户编号, 文件包含平台商及平台商下所有入驻商户的交易信息 | null |
| dayString | 日期 | string | 是 | e.g.: 2017-09-09 | null |

### 请求示例

#### application/x-www-form-urlencoded
**注意：** 如果存在非ASCII的特殊字符，需要对参数值做URL编码两次，不同编程语言对空格URL编码结果不一样，须统一转为`%20`
```
/yos/v1.0/std/bill/dividedaydownload?merchantNo=null&dayString=null
```
