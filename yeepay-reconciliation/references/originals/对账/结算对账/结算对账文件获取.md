# 结算对账文件获取接口

## 基本信息

- **API ID**: eb31ff3ac03b4a78881cc0600054b257
- **API 分组**: settle
- **请求路径**: `/yos/v1.0/settle/file/get`
- **请求方法**: GET
- **描述**: 支持商户进行对账文件下载。 受理失败，返回响应错误码；受理成功，返回文件
- **安全需求**: YOP-RSA2048-SHA256, YOP-SM2-SM3
- **最后更新时间**: 2025-01-16 18:57:56

## 请求参数

### application/x-www-form-urlencoded

| 参数名 | 参数说明 | 类型 | 是否必填 | 描述 | 示例值 |
| ------ | ------ | ------ | ------ | ------ | ------ |
| merchantNo |  | string | 是 | <div><span class="text-only" data-eleid="3">商户编号或入账方id</span></div> | sample_merchantNo |
| parentMerchantNo |  | string | 否 | <p>发起方商编</p> | sample_parentMerchantNo |
| receiverMerchantNo |  | string | 否 | <div><span class="text-only" data-eleid="5">用于下载入账方的结算账单，如果merchantno传入了入账方id，需要传入入账方的归属商编。</span></div> | sample_receiverMerchantNo |
| settleRequestNo | 结算请求号 | string | 否 | 商户发起自助结算时的请求号，当结算日期为空时，此参数必填 | sample_settleRequestNo |
| settleDate | 结算日期 | string | 否 | <p>格式yyyy-MM-dd 需要获取的结算文件对应的结算日期，当结算订单号为空时，此参数必填</p> | sample_settleDate |
