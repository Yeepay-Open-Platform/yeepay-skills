# 交易日对账下载

## 基本信息

- **API ID**: bf91e77fac2b4d6aa7a827bc5bcbcb38
- **API 分组**: std
- **请求路径**: `/yos/v1.0/std/bill/tradedaydownload`
- **请求方法**: GET
- **描述**: 交易日对账下载，具体请参考对账文件说明
- **安全需求**: YOP-RSA2048-SHA256, YOP-SM2-SM3
- **最后更新时间**: 2025-09-12 18:23:24

## 请求参数

### application/x-www-form-urlencoded


| 参数名        | 参数说明 | 类型     | 是否必填 | 描述                                                                             | 示例值  |
| ---------- | ---- | ------ | ---- | ------------------------------------------------------------------------------ | ---- |
| merchantNo | 商户编号 | string | 是    | 标准商户:标准商户编号 平台商:平台商商户编号, 文件包含平台商及平台商下所有入驻商户的交易信息 总店:总店商户编号，文件包含总店及总店下所有分店的交易信息 | null |
| dayString  | 日期   | string | 是    | eg:2017-09-09                                                                  | null |
| dataType   | 数据类型 | string | 否    | 数据类型：merchant:商户对账文件, platform:服务商对账文件，平台商对账文件                                 | null |


### 请求示例

#### application/x-www-form-urlencoded

**注意：** 如果存在非ASCII的特殊字符，需要对参数值做URL编码两次，不同编程语言对空格URL编码结果不一样，须统一转为`%20`

```
/yos/v1.0/std/bill/tradedaydownload?merchantNo=null&dayString=null&dataType=null
```
