# 结算

## 文档定位

本页用于结算能力接入，覆盖申请、查询与结果通知。

- 字段定义、状态与错误码以“接口规范”原文为准。
- 结算链路和接入步骤以“对接流程指引”原文为准。

## 阅读顺序（建议）

1. 先读对接流程，确认结算前置条件。
2. 实现自助结算申请接口。
3. 实现结算记录查询接口。
4. 实现结算结果通知接收与处理。

## 接口规范（What）

- [自助结算申请/必读] `../originals/出款/结算/自助结算申请.md`
- [结算记录查询/必读] `../originals/出款/结算/结算记录查询.md`
- [结算结果通知/必读] `../originals/出款/结算/结算结果通知.md`

## 接入流程（How）

- [结算对接流程指引/必读] `../originals/出款/结算/结算对接流程指引.md`

## Agent 执行提示

- 结算结果以通知与查询双通道确认，不以单次请求返回作为终态。
- 通知处理必须幂等，重复通知不得重复更新结算状态。
