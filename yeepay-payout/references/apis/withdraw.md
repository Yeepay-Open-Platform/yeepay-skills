# 提现

## 文档定位

本页用于提现能力接入，覆盖提现下单、提现查询与提现卡管理。

- 请求字段、状态流转和错误码以“接口规范”原文为准。
- 接入步骤和串联关系以“对接流程指引”原文为准。

## 阅读顺序（建议）

1. 先读提现对接流程指引，确认接入前置条件。
2. 实现提现下单与提现查询接口。
3. 实现提现卡添加、查询、修改/注销接口。

## Agent 执行提示

- 提现属于资金变更操作，必须使用业务唯一流水号并确保幂等。
- 对未知状态应先查提现结果，再决定补偿或重试。
