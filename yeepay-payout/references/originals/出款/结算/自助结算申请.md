# 自助结算申请

## 基本信息

- **API ID**: 1a490c946e8e421fb83dc65a573e392c
- **API 分组**: settle
- **请求路径**: `/rest/v1.0/settle/self-settle/apply`
- **请求方法**: POST
- **描述**: 支持商户发起自助结算申请。
- **安全需求**: YOP-RSA2048-SHA256, YOP-SM2-SM3
- **最后更新时间**: 2025-09-12 16:19:43

### 请求示例

#### application/x-www-form-urlencoded

```
parentMerchantNo=sample_parentMerchantNo&merchantNo=sample_merchantNo&settleRequestNo=sample_settleRequestNo&operatePeriod=sample_operatePeriod&endTime=sample_endTime&settleAmount=10.51&notifyUrl=sample_notifyUrl&bankRemark=sample_bankRemark&extInfo=sample_extInfo
```
