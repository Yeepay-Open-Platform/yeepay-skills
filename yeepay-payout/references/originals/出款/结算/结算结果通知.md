# 结算结果通知

## 结算结果通知

自助结算：商户申请自助结算如传入通知地址，易宝会将结算结果通知给商户。

自动结算：商户如需接收通知，需联系易宝配置通知地址。

### 通知规则

通知失败默认最多重试3次，每次时间间隔300秒；

### 通知参数


| 参数                      | 类型         | 说明                                 |
| ----------------------- | ---------- | ---------------------------------- |
| merchantNo              | string     | 商户编号                               |
| yeepayFlowNo            | string     | 易宝结算订单号                            |
| settleStatus            | string     | 结算状态 SUCCESS 结算成功 SETTLE_FAIL 结算异常 |
| settleRequestNo         | string     | 自助结算时商户传入的结算请求号                    |
| settleAmount            | string(64) | 结算金额                               |
| feeAmount               | string     | 结算手续费                              |
| retreatFlag             | boolean    | 是否有冲退 false：未冲退 ture：已冲退           |
| parentMerchantNo        | string     | 上级商户编号                             |
| settleType              | string(64) | 结算产品                               |
| settleDateCfg           | string(64) | 结算日切时间 只有定时结算返回此参数                 |
| code                    | string     | 返回码                                |
| message                 | string     | 返回信息                               |
| settleRecordDetailsDtos | object     | 出款明细详情                             |
| orderDetailsDtos        | object     | 订单信息详情                             |


出款明细详情(settleRecordDetailsDtos)


| 参数               | 类型          | 说明                                                                                                   |
| ---------------- | ----------- | ---------------------------------------------------------------------------------------------------- |
| errorCode        | string      | 错误码                                                                                                  |
| errorMessage     | string      | 错误信息                                                                                                 |
| realAmount       | string      | 到账金额                                                                                                 |
| status           | string      | 到账状态 SUCCESS：已到账 REMIT_SUCCESS：已到账 ACCOUNTING_FAIL：出款失败 REMIT_FAIL：出款失败 INIT：待处理 REMIT_PROCESS：银行处理中 |
| statusDesc       | string      | 到账状态描述                                                                                               |
| correct          | boolean     | 是否冲退                                                                                                 |
| channelRequestNo | string      | 出款流水号                                                                                                |
| accountType      | string(64)  | 账户类型 ACCOUNT:支付账户 DEBIT_CARD：借记卡 PUBLIC_CARD：对公卡                                                     |
| accountTypeDesc  | string      | 账户类型描述                                                                                               |
| accountNo        | string      | 银行账号，掩码展示                                                                                            |
| accountNameMast  | string      | 账户名称，掩码展示                                                                                            |
| bankCode         | string(32)  | 银行编码                                                                                                 |
| bankName         | string(256) | 银行名称                                                                                                 |


订单信息详情（orderDetailsDtos）


| 参数              | 类型     | 说明    |
| --------------- | ------ | ----- |
| merchantOrderNo | string | 商户请求号 |
| yeepayTrxFlowNo | string | 易宝订单号 |
