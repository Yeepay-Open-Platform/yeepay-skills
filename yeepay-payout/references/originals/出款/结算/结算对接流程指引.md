# **自助结算接入指引：**

自助结算流程图

1、商户业务系统请求【申请自助结算】接口，商户申请自助结算；

接口地址：[https://open.yeepay.com/docs/products/fwssfk/api/postrestv1.0settleself-settleapply](https://open.yeepay.com/docs/products/fwssfk/api/post__rest__v1.0__settle__self-settle__apply)

2、易宝测生产结算订单，异步通知商户结算结果（商户需要在调用【申请自助结算】时传入结果通知地notifyUrl）;

3、商户也可主动调用【查询结算记录】来获取自助结算结果。

接口地址：[https://open.yeepay.com/docs/products/fwssfk/api/getrestv1.0settlerecordsquery](https://open.yeepay.com/docs/products/fwssfk/api/get__rest__v1.0__settle__records__query)

## 结算账户信息说明

在入网的时候关于是否是自动结算还是自助结算是通过产品码来区分的；

结算的方向是结算账户信息json说明中settlementDirection参数来配置的，枚举值如下： `ACCOUNT`：结算到资金账户 `BANKCARD`：结算到银行账户： **开通结算产品时，必填。**

1. # 【自助结算申请】

## 接口描述

支持结算方式为自助结算的商户，通过该接口申请自助结算。

商户可以选择（建议商户0:05之后发起自助结算）：

（1）申请结算当前全部的可结算金额

（2）申请结算某一时间段内的可结算金额

（3）按照指定金额结算

1. ## **请求字段校验逻辑：**

### 必填参数

merchantNo：收款商户编号

settleRequestNo：商户结算请求号(需保证在商户端不重复)

operatePeriod：结算时间范围(枚举值：PERIOD:按照指定的时间区间结算、ALL:结算当前全部未结算可结算交易、AMOUNT:按照指定金额结算，仅当结算产品为班次结算时可用)

### 条件必填参数

endTime：结算时间范围截止时间(条件：operatePeriod为PERIOD，需要填写此参数。D0结算支持结算到秒 D1结算和T1结算支持结算到日)

settleAmount：结算金额(operatePeriod为AMOUNT，需要填写此参数)

### 非必填参数

parentMerchantNo：发起方商户编号

notifyUrl：通知地址(接收结算结果地址，不传则不通知)

bankRemark:银行附言

extInfo:拓展信息，上传信息如下

1. ## 响应参数说明

code ： 返回码

message ：返回信息

parentMerchantNo ：发起方商户编号

merchantNo：收款商户编号

settleRequestNo： 商户结算请求号

yeepayFlowNo：易宝结算订单号

响应参数中code仅代表业务的受理情况，

（1）当code=000000时，说明易宝已受理该笔自助结算申请，实际的结算结果请以「自助结算结果通知」中settleStatus来判断结算结果

（2）当code≠000000时，说明易宝未受理该笔自助结算申请，可根据返回的 message 进行相应处理。

1. # 【结算记录查询】
2. ## **请求字段校验逻辑：**

### 必填参数

merchantNo：商户编号或入账方id

### 条件必填参数

settleRequestNo:结算请求号(结算请求号与结算申请起止时间二选一必填)

settleRequestBeginTime:结算申请起始时间（结算申请起止时间与结算请求号二选一必填）示例值：2020-12-01 00:00:00

settleRequestEndTime:结算申请截止时间（结算申请起止时间与结算请求号二选一必填）示例值：2020-12-01 00:00:00

商户结算请求号和结算申请起止时间不能同时为空!

### 非必填参数

parentMerchantNo:发起方商编

receiverMerchantNo入账方的归属商编

1. # 【结算结果通知】

自助结算：商户申请自助结算如传入通知地址，易宝会将结算结果通知给商户。

自动结算：商户如需接收通知，需联系易宝配置通知地址。

### 通知规则

通知失败默认最多重试3次，每次时间间隔300秒；
